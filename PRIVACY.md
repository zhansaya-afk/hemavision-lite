# Приватность

| Что | Где | Как удалить |
|---|---|---|
| Фото | Только в памяти страницы во время анализа. Не сохраняется и никуда не отправляется | Закрыть приложение |
| Миниатюра фото (160 px) | IndexedDB этого браузера, **только если отмечена галочка** | «История» → «Удалить всю историю» |
| Результат: дата, зона, EI, a\*, L\*, HHR, качество, версия модели | IndexedDB этого браузера, по кнопке «Сохранить в историю» | То же |
| Ответы опроса | Только в памяти на время сеанса (в отчёт попадают возраст и пол, без ФИО) | Закрыть приложение |
| Язык и отметка «согласие дано» | localStorage | Очистить данные сайта в браузере |

- После установки приложение не делает сетевых запросов: все файлы берутся из кэша service worker.
- Нет аналитики, рекламы, сторонних шрифтов и CDN. CSP запрещает загрузку чего-либо не с нашего адреса.
- Отчёт для врача формируется на телефоне и сохраняется в PDF средствами браузера.
