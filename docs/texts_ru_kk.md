# HemaVision Lite — тексты интерфейса и подсказок (RU / KZ)

Версия 2026-11-23, заготовка к туру 26.11. Это **тексты, не код** (п. 5.1). В туре их переносят в `i18n/ru.json` и `i18n/kk.json` по ключам из первой колонки.

- Казахский — черновик Claude, термины сверены с базой Personalizer (`kk.md`: «жалпы қан анализі», «төменгі қабақ», «көздің ағы», «жедел жәрдем 103 немесе 112»). **До показа жюри — проверка носителем языка.** Если не успеваете — в MVP только RU, переключатель языка скрыть.
- `{x}` — подставляемое значение. Длина кнопок ≤ 18 знаков, чтобы влезать в 360 px.
- Правило: нигде не пишем «анемии нет», «здоров», «уровень гемоглобина», «точность 9x %». Пишем «риск по фото», «скрининг», «сдайте ОАК».
